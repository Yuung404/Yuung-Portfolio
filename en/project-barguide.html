CONTEXT & ORIGIN

BarGuide is a bar guide web application I designed and built entirely on my own, outside of any school assignment. The concept is straightforward: have all official IBA cocktail recipes, world beers, wines, coffees and shots at your fingertips — with recipes generated on demand by Claude AI (Anthropic).

This project gave me hands-on experience in front-end development with React, taught me how to integrate an AI API in a production environment, and let me deploy a complete application with an autonomous CI/CD pipeline.

WHAT I BUILT

1. Application architecture (React + Vite)
I structured the project from scratch: entry point main.jsx, main component App.jsx handling UI and data, and a dedicated api.js module for Anthropic calls. No component library — all CSS is injected via CSS-in-JS with hand-written keyframes.

2. Drinks database (190+ entries)
I manually built the database: 102 official IBA cocktails (Unforgettable, Contemporary, New Era), 52 world & craft cocktails (Spain, Mexico, Peru, UK, NYC…), 36 specialty beers (Trappist, Sour, NEIPA, Gueuze, Bock…), 10 wines & sparkling, 15 coffees, 20+ mocktails, shots, sangrias and digestifs.

3. Claude API integration (Anthropic)
Each cocktail card generates its recipe on demand via claude-haiku-4-5. I implemented a session cache to avoid redundant API calls, and a static fallback on pre-saved recipes if the API is unavailable.

4. TheCocktailDB integration
For IBA cocktails, I connected the public TheCocktailDB API to display a real cocktail photo on each card.

5. Realistic SVG glasses
I created 16 different glass types in SVG (Martini, Old Fashioned, Highball, Coupe, Shot, Pint, Tulip…) with liquid fill and light reflections. Each card displays the ideal glass plus 2 clickable alternatives.

6. Equipment modes
The app offers 3 modes depending on what the user has at home:
▸ IDEAL — full bartender kit recipe
▸ IMPROVISED — 3 alternatives per missing ingredient
▸ NOTHING — improvised measures guide (cl → everyday household items)

7. Search and filters
Instant global search across name, origin, ingredients and IBA category. Sub-category filters. Smooth animations: cascading cards, background float, animated modal, hover glow effects.

8. CI/CD and deployment
GitHub Actions pipeline for automatic build and deployment to GitHub Pages on every push to master. The app is also deployed to Vercel in production, with a backend proxy to keep the Anthropic API key out of the client bundle.

PROJECT EVOLUTION

The project evolved through successive iterations, each commit representing a concrete feature or improvement:

▸ v1 — Initial prototype: 38 cocktails, basic AI generation, minimal interface
▸ v2 — GitHub Pages added, tested Gemini API (free tier), then switched back to Claude Haiku for recipe quality
▸ v3 — Full rewrite: 190+ entries, SVG glasses, equipment modes, session cache, TheCocktailDB, animations, Vercel production
