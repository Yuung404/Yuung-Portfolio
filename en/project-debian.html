CONTEXT & GOALS

The company SIDEL needs a Linux server for its internal services. Lab 1 is about installing a minimal Debian server and securing remote access; Lab 2 turns it into a web server hosting several sites.

WHAT I BUILT

1. Minimal installation
Debian 13 in text mode, no desktop: fewer packages, fewer vulnerabilities. A root account for administration and a standard account yuung for daily use. A GNOME desktop had been installed by mistake: I reinstalled, checking every option.

2. Securing remote access
Added my account to the sudo group (usermod -aG sudo yuung), blocked root over SSH (PermitRootLogin no, checked with sshd -T), then Fail2ban against brute force: 5 failures and 1 ban recorded during my tests.

3. Web server and virtual hosts
Static IP, Apache 2.4, PHP 8.4 and MariaDB, then two sites on one server, site1.sidel.local and site2.sidel.local, each with its own ServerName, DocumentRoot and logs. Tested from the PC through the hosts file, and without it using curl.exe -H "Host: …".

4. Web-based administration
Installed Cockpit, the administration interface served over HTTPS on port 9090 with the standard account.
